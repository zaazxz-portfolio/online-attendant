# Sistem Informasi KKN (Kuliah Kerja Nyata)

Aplikasi web berbasis PHP Native untuk mengelola administrasi, pendaftaran, dan kegiatan Kuliah Kerja Nyata (KKN).

## Fitur
- Manajemen pengguna (Admin & User)
- Autentikasi sistem
- Pencetakan dokumen berbasis PDF (menggunakan Dompdf)

## Persyaratan Sistem
- PHP >= 8.1
- Composer

## Menjalankan Proyek
1. Instal dependensi:
   ```bash
   composer install
   ```
2. Jalankan server lokal:
   ```bash
   php -S localhost:8000 router.php
   ```
